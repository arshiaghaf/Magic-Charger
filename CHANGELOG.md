# Changelog

This records source-preview changes. Magic Charger has no downloadable release yet.

## Unreleased

- Added public contribution guidance, device validation checklist and issue templates.

## 0.1 source preview — 2026-10-21

- Added native controls, per-device charging menu items and independent display preferences.
- Added optional Charging Started, 78%, 80% and 100% local alerts with conservative session handling.
- Added narrow Magic Mouse and Magic Keyboard Bluetooth charging profiles observed on macOS 27.2.x.
- Added privacy, architecture, support and security documentation, deterministic tests and a local app build script.

The 0.1 entry describes the initial public source; it is not a signed or notarized app release. Real threshold crossings, broader hardware/OS support and several live UI behaviors remain pending validation.
